# Sleep consolidation

Nobody approves a sleep. The deterministic half settles dates, weight, links and
directories by rule. The judged half drafts merge, split, supersede and deletion
proposals from the menu the core wrote, and a reasoner that can only choose from
that menu rules on them, capped per kind per sleep.

Every sleep leaves a report, and a git commit when the store lives in a repository.
No operation removes a file: invalidation ends the validity interval and keeps the
file for historical reads. Physical removal is a human-run command the sleep layer
cannot reach. A wrong call stays visible and reversible from outside the loop.
