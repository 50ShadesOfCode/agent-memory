# Read paths

Reads never mutate truth files. Usage signals land in the index access log only;
weight settles back into frontmatter through Manage in batch.

Three tracks divide labor. Injection carries a byte-prefix of the injected index,
never a summary, so truncation cannot cut a line mid-way. Recall ranks eligible
memories by relevance, weight and recency with no model involved. Context runs the
same retrieval and opens the top entries to full text in one call, so the store
decides when to stop instead of the agent driving its own ladder.

The default surface holds active files only. History is available through one
explicit reader that judges a file by its validity interval, never by its text.
Scope filters before candidate limits, so unrelated matches cannot hide a relevant
scoped memory. Feedback is a usage signal for later settlement, not an immediate
file write.
