# Entry adapters

Adapters carry zero algorithm. CLI, MCP and hooks collapse into the same core calls;
the same request through any entry yields the same result.

Lifecycle adapters translate host events into injection, pause and eviction moments.
Capture archives the transcript increment and advances the watermark under the store
writer lock, never distilling. Executor dialects translate a prompt and tool posture
into one headless host invocation and normalize only the final answer. The library
core holds no model client; reasoning arrives through the host CLI by default or an
explicitly configured operator-owned endpoint.
